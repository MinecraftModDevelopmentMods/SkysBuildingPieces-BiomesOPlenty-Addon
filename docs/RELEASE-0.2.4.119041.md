# Minecraft 1.19.4

Use Forge 45.4.0, Java 17, Building Pieces 0.3.8.119041, Biomes O' Plenty
17.3.0.593 and TerraBlender 2.3.0.22. Install matching main jars on both sides.

Building pieces keep their materials, orientations and waterlogging. Flower
Baskets keep their contents. Removed mud pieces use vanilla equivalents;
rooted sand and removed biomes use the replacements in the
[world-upgrade guide](WORLD-UPGRADES.md). Test a copy before upgrading.
