# Minecraft 1.18.2

Use Forge 40.3.0, Java 17, Building Pieces 0.3.8.118021, Biomes O' Plenty
16.0.0.134 and TerraBlender 1.2.0.126. Install matching main jars on both sides.

Building pieces keep their materials, orientations and waterlogging. Flower
Baskets keep their contents. Removed roots and biomes use the replacements in
the [world-upgrade guide](WORLD-UPGRADES.md). Test a copy before upgrading.
