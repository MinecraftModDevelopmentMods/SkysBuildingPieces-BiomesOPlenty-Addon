# Minecraft 1.17.1

This version uses Forge 37.1.1, Java 16, Building Pieces 0.3.8.117011 and
Biomes O' Plenty 14.0.0.43. Install the matching main jars on both sides.

The existing pieces and Flower Basket keep their saved identities, orientations,
waterlogging and stored contents. Recipes appear in the recipe book as their
ingredients are collected. Nether crystals removed by BOP become rose quartz
clusters or full blocks, keeping their attachment direction and item data.

Back up an existing world and try a copy first. See [world upgrades](WORLD-UPGRADES.md)
for the supported replacements and the limits of older BOP content recovery.
