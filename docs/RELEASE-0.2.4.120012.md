# Building Pieces BOP for Minecraft 1.20.1

Use NeoForge 47.1.106, Java 17 and Building Pieces 0.3.8.120012. Install Biomes
O' Plenty 18.0.0.598 and TerraBlender 3.0.1.10 on both the client and server.

Existing pieces and Flower Baskets keep their shapes, slots and contents.
Older BOP cherry blocks use Minecraft's cherry equivalents. White cherry
plants become Snowblossom, and BOP 18 keeps its original autumn leaves and
saplings. See the
[world upgrade guide](WORLD-UPGRADES.md) for the other replacements.
