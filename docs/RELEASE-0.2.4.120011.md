# Building Pieces BOP for Minecraft 1.20.1

Use Forge 47.4.10, Java 17 and Building Pieces 0.3.8.120011. Install Biomes
O' Plenty 19.0.0.96, TerraBlender 3.0.1.10 and GlitchCore 0.0.1.1 on both the
client and server.

Existing pieces and Flower Baskets keep their shapes, slots and contents.
Older BOP cherry blocks use Minecraft's cherry equivalents. Snowblossom and
the matching maple colours take the place of retired plants. See the
[world upgrade guide](WORLD-UPGRADES.md) for the other replacements.
