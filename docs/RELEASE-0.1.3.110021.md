# Biomes O' Plenty add-on 0.1.3 for Minecraft 1.10.2

Update this add-on together with Sky's Building Pieces 0.3.7. You can rebuild
larger BOP pieces by stacking two matching corners for a step, or two matching
steps for a regular slab.

The materials, textures, block IDs and palette slots are unchanged. Existing
builds keep their pieces and orientations. This update still requires Biomes
O' Plenty 5.0.0.2236 and adds no terrain generation.
