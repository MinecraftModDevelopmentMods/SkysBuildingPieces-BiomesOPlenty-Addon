# Sky's Building Pieces — Biomes O' Plenty 0.2.7.2603002

For Minecraft 26.3 and NeoForge.

Wooden pieces use fuel values that match their size, with hellbark excluded. Recipe-book results are easier to browse. Saved basket checks cover modern chunk compression and oversized chunks without reading unrelated mod data files.

Retired-rock recipes unlock with the available material, including the fallback
rocks when Mineralogy is not installed.
