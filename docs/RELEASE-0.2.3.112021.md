# Sky's Building Pieces — Biomes O' Plenty 0.2.3 for Minecraft 1.12.2

This update uses Building Pieces 0.3.7.112021. Stack two matching corners in the
crafting grid to make a step, or two matching steps to make a regular slab.
Materials with native BOP slabs use those slabs.

The material catalogue, block IDs and saved pieces are unchanged. Flower
Baskets keep their storage and automatic plant collection.

Use Forge 14.23.5.2859, Building Pieces 0.3.7.112021 and Biomes O' Plenty
7.0.1.2445. Grass Slabs is optional; use its 1.1.1.112021 release when installed.
